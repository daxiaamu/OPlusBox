### AirDrop 支持

通过“快速分享”与苹果设备互相发送和接收文件，仅支持部分较新的设备。需要 ROOT、LSPosed 和匹配的 Google 服务／无线后端；缺失组件由盒子按需下载安装，部分设备需要重启。以应用实际检查结果为准。
