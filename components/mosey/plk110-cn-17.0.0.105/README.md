# Mosey 云端组件

本目录仅保存官方组件部署资产及签名安装清单，不包含 OPLUSBox 应用源码。

- 适配系统：PLK110 `17.0.0.105(CN01)`，ColorOS 17；安装器还校验原厂配置文件和无线驱动。
- 当前组件修订：1；ZIP 4,300,258 字节，SHA-256 `d0e5ef8f9780b147ee2dc99019def10b154c68c7e888ba84aa4ab8397002867c`。
- 内容：Google 签名的 Mosey APK、官方用户态服务和库、早期 init/VINTF 及权限配置。没有内核或 WLAN 驱动模块。
- 安装和更新均由盒子检查兼容性、验证清单签名、完整下载并校验 ZIP 后，通过支持早期 init 注册的 ROOT 环境部署。完成后需重启，再重新开启功能执行运行检查。
- 组件 ZIP 使用独立修订目录和不可变提交地址；CDN 失败会自动尝试备用源。清单发布前要求至少五个不同 CDN 主机完整下载并验证字节数和摘要。
- 未适配系统不会强行安装。单独侧载 Mosey APK 不能完成系统集成。

该适配结果不能推广为所有 ColorOS 17 设备均支持。
